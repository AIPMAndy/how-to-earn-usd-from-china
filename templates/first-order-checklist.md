# 海外第一单交付清单

| 要确认的内容 | 本单应写清什么 |
|---|---|
| 客户与收款主体 | 交易双方真实身份与所在地 |
| 具体问题 | 客户为什么要付费 |
| 服务范围 | 包含与不包含哪些事项 |
| 输入与权限 | 客户提供什么资料，允许访问哪些系统 |
| 交付物 | 具体文件、功能、报告或服务次数 |
| 里程碑 | 开始时间、检查时间、最终交付日期 |
| 验收标准 | 客户怎样确认工作完成 |
| 修改次数 | 包含几轮修改，额外变更如何收费 |
| 价格和币种 | 价格、付款节点、退款和第三方费用 |
| 保密与版权 | 数据和最终成果的权利与使用范围 |
| 售后维护 | 是否含维护及期限 |

## 签约前

- [ ] 客户有明确需求且付款责任人明确
- [ ] 交付范围、金额、币种、付款方式双方确认
- [ ] 收款渠道与真实经营主体、身份及交易相符
- [ ] 敏感客户数据与访问权限经过正式授权

## 交付前

- [ ] 结果符合验收条件，保留书面确认
- [ ] 检查事实错误、代码安全、素材和版权问题
- [ ] 核对订单、付款、发票与必要的税务和银行材料

此表是沟通模板，不替代具体交易适用的合同和专业意见。
