# 美元收款后的凭证清单

| 时点 | 需要保存什么 |
|---|---|
| 报价 | 报价单、业务范围、客户主体 |
| 签约 | 合同、订单、交易条款 |
| 履约 | 交付文件、修改记录、完成确认 |
| 收款 | 平台流水、银行交易单、实际汇率和手续费 |
| 退款 | 退款凭证、双方确认的退款说明 |
| 记账 | 与实际主体及收入性质相符的账务和发票材料 |
| 申报 | 银行、税务部门要求的其他对应凭证 |

个人结售汇便利化额度不等于所有合法收入的绝对上限。经营性收款可能有不同规则，实际办理以银行和适用监管要求为准。

**重要隐私规则** 这些材料只保存在有权限的账户或业务系统中，不要上传公开 GitHub Issue 或分享给陌生人。
