# 海外服务范围与报价说明

Client / 客户

Problem / 客户希望解决的问题

Scope / 本次包含的任务

Exclusions / 不包含的事项

Deliverables / 交付物

Timeline / 各阶段日期

Acceptance / 验收方式

Revisions / 修改次数和额外收费

Currency and fee / 货币与价格

Payment milestones / 付款条件

Confidentiality / 数据和保密条款

Maintenance / 售后或维护

## Example email

Subject — Proposal for [specific project]

Hi [First name],

Thanks for sharing the details. I can help with [specific problem]. The deliverables would be [A], [B], and [C], with a target completion date of [date].

My project fee is USD [amount], split into [payment milestones]. This includes [number] revisions. Anything outside the agreed scope would be quoted separately.

If this fits your needs, I can send the final scope for review.

Best,  
[Your name]

根据真实情况修改后再发送。
