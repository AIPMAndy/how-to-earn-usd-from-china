# 中国人赚美金保姆级攻略

![中国人赚美金保姆级攻略](assets/cover.svg)

**一个中国人，一台电脑，怎样从第一笔美元收入走向长期海外生意**

本项目由 **AI 酋长 Andy** 整理。我结合 AI 产品、职业咨询、海外内容和开源实践的经验，研究中国人如何把已经掌握的专业能力卖给海外客户。

这份指南直接给答案。业务怎么选，客户去哪找，怎么报价与交付，钱怎么收回来，如何处理税务，以及什么时候该做产品和公司主体。

## 八条美元收入路线

| 方向 | 推荐给谁 | 典型交付 |
|---|---|---|
| 专业咨询 | 产品、职业顾问、行业专家 | 一次诊断、咨询与方案 |
| 开发与 AI 自动化 | 开发者、AI 产品从业者 | 企业工具、自动化流程 |
| 设计与视频 | 设计与剪辑人员 | 营销素材、落地页、视频 |
| 内容与增长 | 运营、SEO 从业者 | 内容和流量转化服务 |
| 中国供应链协助 | 外贸、制造、采购人员 | 寻源、样品、质量协助 |
| 本地化 | 双语专业人士 | 技术资料、产品本地化 |
| 数字产品 | 有可复用专业内容的人 | 模板、资料库、课程 |
| 小型 SaaS | 能持续维护产品的团队 | 订阅服务、企业软件 |

## 我最建议的方向

普通人先保持原来的专业优势，找到愿意为这项能力付款的海外客户。接一笔真实的小订单，把交付和合规收款跑通，然后考虑复购、长期合作和产品化。

从国内接单起步时，**不需要预先购买美国地址、冒用身份，也不用为了开 Stripe 先成立没有真实经营计划的公司**。收款路径应以交易类型、实际主体和当前支持地区为准。
