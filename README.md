## 我建议的顺序

先有明确客户，再确认服务边界、报价与验收。第一笔订单完整走完合同、交付、付款和依法办理的结算手续。遇到同样的问题重复出现，再逐步做成课程、工具或订阅产品。

**美国客户付美元，并不意味着中国居民自动取得境外来源所得。个人每年等值五万美元的结售汇便利化额度也不是所有合法收入的绝对上限。** 具体要按交易性质、提供服务地点、个人或企业主体和官方要求处理。原始来源都放在[资料索引](docs/SOURCES.md)。
