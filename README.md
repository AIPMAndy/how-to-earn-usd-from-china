## 我为什么建议先接服务，再做产品

刚开始通常不缺工具，缺的是明确需求、真实客户和能收到的款项。先用自己熟悉的专业能力完成小订单，往后更容易判断哪些交付值得做成课程、工具或订阅业务。没有订单时，先解决客户和报价问题；有订单以后，再解决复购和规模化。

海外客户付美元，不意味着你可以忽略中国的外汇、税务、合同和个人信息保护要求。**支付工具支持地区、平台提现资格和结汇材料，请以真实主体和官方最新规则为准。**
