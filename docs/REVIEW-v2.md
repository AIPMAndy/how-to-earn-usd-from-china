# 对抗式审核记录 · v2.0

本记录对应公开指南与网站。审核重点在可执行、可核验、不会误导交易、可以合法收款，以及读者如何联系作者。

| 反方问题 | 风险 | 处理办法 | 页面位置 |
|---|---|---|---|
| 读者看完不知道卖什么 | 八条方向太多 | 按七类起点给出第一项可卖服务，首页提供即时匹配工具 | 第十一章与路线筛选器 |
| 把海外高价服务当成人人可得的机会 | 忽略语言、时间、作品和平台准入 | 提醒价格仅作演示，优先用已有能力选择明确范围的服务 | 第十一、十二章 |
| 30 天计划被理解为保证出单 | 不切实际的收益预期 | 只要求读者完成可控动作，没成交有四项诊断 | 第十三章 |
| 没有合同直接收款 | 交易纠纷、结算风控 | 添加报价、授权、验收、资金凭证清单 | 第十四章 |
| 向公共模型上传客户资料 | 商业秘密和个人信息风险 | 明示需要客户授权、最小权限和脱敏 | 第十二至十五章 |
| 微信联系方式过度营销 | 影响阅读信任 | 网站保留攻略优先，首屏和页尾提供微信复制与个人网站 | 首页、文章结尾 |
| Stripe 和国际平台支持条件变化 | 账户被拒、资金冻结 | 资料保留官方链接，实际申请以账户所在地、业务类型与最新规则为准 | 第五、六章和官方来源 |
| 美国客户支付即被误当作境外所得 | 税务判断错误 | 按中国税收居民、实际服务地点及交易性质核对，不自定规则 | 第六章 |
| 模板里的报价被理解为市场价 | 误导消费者 | 将金额标注为演示示例，报价需结合范围、费用、风险与客户 | 第十二章 |
| 成交截图与案例被夸大 | 虚假宣传与隐私风险 | 没有授权不公开客户与订单，个人作品标注演示 | 第十一、十五章 |
| 页面在手机上无法阅读 | 关键内容折行或溢出 | 390、430、1280 宽度检查，表格横向可滚动 | 全站 |
| 互动筛选器让用户误以为官方评估 | 过度信任自动推荐 | 说明仅是职业经验匹配规则、不收集信息、不保证结果 | 首页 |

下一次更新应逐项复核平台支持国家、收款费用、税务适用条件和外链可用性。发现已失效的内容应注明更新时间与官方来源，并接受 GitHub Issue 指正。
