# 项目更新路线

本项目长期关注中国大陆用户跨境提供服务和经营的实际问题。

## 当前完成

- 16 章中文长文、8 条业务路径和 4 张可缩放矢量信息图
- 海外获客与英文私信报价
- 中国大陆主体收美元、外汇与税务核查资料
- GitHub Pages、英文项目介绍、导航、SEO 与自动检查
- 真实案例与政策更正的公开 Issue 模板

## 下一轮优先维护

- **支付平台资格** 持续核对中国大陆个人和企业的支持情况，记录核验日期
- **真实案例** 只收集授权可公开、能说明交付成果的经历
- **报价与行业模板** 按 AI 产品、开发、设计、运营、外贸服务分别细化
- **英文内容** 补充让海外读者也能理解的业务服务边界
- **网站体验** 提升移动阅读、页面加载与搜索可访问性

## 如何判断是否值得新增内容

读者是否遇到真实问题，资料是否有官方来源，是否能给出可以采取的具体步骤，以及有没有权限公开案例。没有证据的数字与收入预测不进入指南。
