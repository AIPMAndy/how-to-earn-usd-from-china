# 常见问题

## 必须先注册美国公司吗

可以先用有资格的中国大陆个人或公司主体开展服务，按具体平台和银行规定接单。只有真实业务需要时，再评估境外主体的成本、申报、税收和维护义务。

## 有美国 IP 能直接注册美国收款账户吗

IP 不能替代真实地址、法定主体、税务和账户审核材料。不要提供虚假身份。

## 美国客户付款，就一定是境外所得吗

不能只按付款人所在地判断，需要按中国适用规则区分劳动及劳务实际地点、业务性质、税务居民身份和所得类别。

## 5 万美元是赚钱上限吗

不是。个人结售汇年度便利化额度与经营性跨境收款规则应当区分。真实合法的经常项目可按要求提供材料办理。

## X 的会员费可以换来美元分成吗

付费会员不能保证有平台收益。规则、资格和地区会变化。把 X 作为获客与展示专业能力的渠道更实际。

## 怎样知道客户有没有真实付款能力

核查公司和联系人、签署书面范围约定、分阶段交付、保留记录，警惕押金、代付款、异常加密货币转账等骗局。
