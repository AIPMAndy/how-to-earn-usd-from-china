# 第一次看这份攻略，直接找答案

**还没有客户。** 先看 [八条可做的生意](01-business-paths.md)，沿着自己已经会的专业能力选一项明确服务，再看 [怎么找客户与报价](03-customers-and-delivery.md)。

**客户已经询价。** 用 [第一单交付清单](../templates/first-order-checklist.md) 写清范围、成果、工期、付款节点、验收和售后。不要承诺没有确定边界的项目。

**马上要收美元。** 区分个人与企业、服务与货物、平台与直接付款，再看 [收款税务指南](02-payment-tax.md) 和 [材料清单](../templates/payment-records.md)。真实身份和交易性质是开户及结算的基础。

**准备做长期业务。** 等真实订单产生重复需求，再逐步考虑包月服务、模板、工具或软件订阅。不要只凭一笔意外收入规划全年现金流。

有疑问可到 [Issue 区](https://github.com/AIPMAndy/how-to-earn-usd-from-china/issues/new/choose) 提问或补充可核验的资料。
